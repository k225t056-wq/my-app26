# Game Profile Card Generator

簡単・綺麗・高画質にゲームの自己紹介カードを作成できるアプリです。

## 🚀 Live Demo
[https://k225t056-wq.github.io/my-app26/](https://k225t056-wq.github.io/my-app26/)

## ✨ 特徴
- **文字ズレ防止**: Canvas APIによる固定ピクセル描画を採用。
- **高解像度**: SNSに最適な 1920x1080 (Full HD) 出力。
- **簡単操作**: 情報入力と画像アップロードだけで即完成。
